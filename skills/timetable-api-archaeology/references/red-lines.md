# 红线

违反其中任一条，这次观测就应当中止。它们不是风格建议：每一条对应一个
**会影响别人账号、别人数据或别人学业的后果**。

## 凭据

- 凭据**永远由用户本人输入**。Agent 不代填、不读取、不保存、不截图。
- 不把会话文件（`storage_state`、Cookie jar）的内容打印进对话、日志或提交。
- 不要求用户把密码贴进聊天里"我来登录"。需要登录就把命令交回用户自己的前台终端。
- 不持有、不代管任何人的账号。做中心托管服务、内置任何学校的账号入口都是同一类错误。
- 会话文件目录要在 `.gitignore` 内，写入用私有权限。

## 合规

- 目标学校条款若禁止程序化访问，或读不出结论，**停**。承担后果的是学生的账号，
  不是发布工具的人。
- 不绕过统一身份认证、验证码、扫码、双因子。"绕过去"从来不是可接受的实现细节。
- 不探测非本人可见的数据：不枚举学号、不遍历课程、不构造他人课表请求。
- 不高并发、不重试轰炸、不在失败时循环撞限流。一次登录、一次只读请求、串行。
- 请求频率保持在"用户自己刷新页面"的量级。

## 隐私与落盘

- 原始响应含学号、姓名、教师姓名、课程名、考场、座位。它们**只留在仓库之外**。
- 进仓库的样本必须先脱敏，占位值要一眼可辨为假（`示例课程甲`、`演练楼-101`），
  不要用近似真实的姓名。
- 跟踪内容不得出现真实姓名、学号、订阅 token、本机绝对路径。
- 日志与报告只记端点、方法、参数**键名**与响应**结构骨架**，值一律脱敏。
- 提交前跑一次隐私 grep，搜姓名/学号样式、绝对路径与 token 特征。

## 措辞

- **未验证的表现不许写成事实。** 客户端对撤销字段的处置、回源周期、改名会不会跟着变——
  没有真机读数就写「通常会」，并明确标注未验证。
- 单一账户单一样本的实测结论要带限定语，不得写成厂商承诺或普适规律。
- 两处描述同一事实时指定一个权威版本，另一处只留"同步于 <commit>"的标记；
  没有同步标记的副本就是漂移的起点。
- 说不清就写"不知道，需要 X 才能判断"。含糊的乐观结论比空白更贵——
  下一个人会把它当依据。

## 范围

- 本方法论**不产出可用订阅**。接口跑通不等于能发布日历：还要校历、作息、
  学期口径、隐私口径与合规结论全部落地。
- 不要把"另一所学校也能用"写进任何 README 或承诺里，直到有人带回该校脱敏后的
  完整观测清单。
- 遇到 `SKILL.md` 第 4 步的任何停止条件，输出「我停在哪、需要什么才继续」，
  这就是这次任务的正确交付物。
