# xjtu-timetable-calendar

将西安交通大学 eHall 个人课表导出为标准 iCalendar（`.ics`）文件，便于导入手机、电脑或其他日历应用。

> 项目仍处于早期开发阶段。

## 项目目标

学校课表通常只能在教务系统中查看，不方便和日常日历、会议、提醒事项放在一起管理。

本项目计划实现：

- 获取当前账号有权访问的个人课表
- 解析课程名称、教师、地点、星期、节次和周次
- 正确处理单双周、非连续周等课程安排
- 将课表转换为标准 iCalendar（`.ics`）
- 导入 Apple Calendar、Google Calendar、Outlook 等日历应用
- 尽量减少重复事件与错误时间
- 后续支持课表变化后的增量更新

## 数据来源

课表数据来自西安交通大学 eHall 中当前登录账号能够正常访问的个人课表页面。

本项目不会尝试：

- 绕过统一身份认证
- 绕过课程或用户权限控制
- 查询其他用户的个人课表
- 批量枚举无权限数据

## 计划中的工作流程

```text
西安交通大学统一身份认证
              ↓

              ↓
