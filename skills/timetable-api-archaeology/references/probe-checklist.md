# 观测清单（可勾选）

一次只读观测的产物就是这张表填完。**每一项都要写出证据出处**（响应里的字段名、
样本文件名、第几行），没有证据的格子留空并说明为什么拿不到。

## 0. 前置（不通过就别往下）

- [ ] 目标学校条款是否允许程序化访问？出处：____（条款原文位置）
- [ ] 使用的是用户**本人**账号？
- [ ] 探测只读、单次、串行，无并发与重试轰炸？
- [ ] 原始响应的落盘位置在仓库之外？

## 1. 接口发现

- [ ] 课表接口 URL / method / 参数名清单（值一律脱敏）
- [ ] 是否在新标签页或 iframe 内发起？（只监听初始页面会全部漏掉——本校踩过）
- [ ] 响应 `content-type` 是什么？（`text/plain` 或 HTML 包裹的 JSON 都见过，
      按 content-type 过滤会把接口整个丢掉）
- [ ] 是否存在第二个数据源（考试、通知、作息）？路径是否与课表关键词不同？

## 2. 一问：字段映射

| 语义 | 实际字段名 | 证据 | 备注 |
|---|---|---|---|
| 课程名 | | | |

| 教学楼 / 教室 | | | |

- [ ] 解析跳过的行有逐条报告，而不是静默消失

## 3. 二问：周次形态

- [ ] 属于哪一类：位掩码 / 文本 / 日期区间
- [ ] 位掩码：从右起还是左起是第 1 教学周？总位数是多少？
- [ ] 文本：把该系统的写法各取一个实例（普通周、单双周、区间、"第 X 周"），
      逐条写出解析结果
- [ ] 用一门已知"只在双周上"的课做判据：第 3 周有没有它？

## 4. 三问：学期发现与身份字段

- [ ] 学期代码字符串格式：____（例：`2026-2027-1`）
- [ ] 当前学期从哪个接口/字段得出？会不会与服务端"默认学期"不一致？
- [ ] 同一账号连续两次抓取，学期代码完全一致？
- [ ] 身份字段候选：____
- [ ] 对照实验：改一次上课时间再抓，该字段的值**没变** → 可用；变了 → 换一个候选
- [ ] 若无稳定身份字段：记录"只能整份重新导入"，并停止增量/撤销设计

## 5. 四问：三态可区分性（go / no-go）

- [ ] 「有数据」「确实没有」「查询失败」三态在响应里分别长什么样？
- [ ] 区分信号是什么字段？（本校：`extParams.code == 0` 配合失败文案）
- [ ] 专门制造一次"查询失败"（例如带一个过期会话）看响应，
      与"真的没有数据"的正常响应**是否字节级可分辨**？
- [ ] 结论：**可用 / 不可用**（区分不了就是不可用，不是"稍差"）
- [ ] 分页：响应行数 == 响应声明的总数？不等就说明只拿到一页

## 6. 对照探针（判断客户端行为时必做）

- [ ] 这次要判的信号是什么？
- [ ] 与之配对的**必然可见**的变化是什么？（改时间、改标题——不是只加一个字段）
- [ ] 可见变化**出现了**吗？没出现说明发布链路没生效，前面所有"没变化"的结论作废
- [ ] 发布产物用匿名 GET 拉回来核对过内容？
- [ ] 记录观察起止时间与每次读数时刻（客户端回源周期以小时计，不可强制刷新）
- [ ] 结论措辞：未确认的一律写「通常会」并注明未验证

## 7. 落盘与提交

- [ ] 原始响应存在仓库外
- [ ] **进仓库的样本已脱敏**：学号、姓名、教师姓名、课程名、考场、座位、
      token、Cookie 全部替换为可识别为假的占位（`示例课程甲`、`演练楼-101`）
- [ ] 脱敏后用隐私 grep 搜过一遍真实标识
- [ ] 观测记录写清学校、接口、观测日期、账号数量与样本数量（单样本要说明是单样本）
